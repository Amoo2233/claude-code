FAQ

Questions, answered

Do I need a build tool?+

No. Nova is plain HTML, CSS, and vanilla JavaScript. Open index.html in any browser and it just works.

How do I change the colors?+

Edit the CSS custom properties at the top of styles.css. Every component reads from those tokens, so a few edits restyle the whole site.

Is it accessible?+

Yes — semantic landmarks, keyboard navigation, visible focus states, ARIA where needed, and prefers-reduced-motion support.

Can I use it commercially?+

Absolutely. Use it as the foundation for landing pages, portfolios, docs, or product sites.
