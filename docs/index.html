Claude Code understands your codebase and helps you code faster by executing routine tasks, explaining complex code, and handling git workflows — all through natural language. Use it in your terminal, your IDE, or by tagging @claude on GitHub.

Capabilities

Your codebase, handled end to end

From a one-line prompt to a finished commit — Claude Code plans, edits, runs, and verifies.

>_

Works where you work

Run it in any terminal, in VS Code and JetBrains IDEs, on the web, or in GitHub Actions by tagging @claude on issues and PRs.

{}

Understands your codebase

Searches, reads, and maps your project before making changes, so edits match your existing patterns and conventions.

⎇

Handles git workflows

Creates branches, writes commits, resolves conflicts, and opens pull requests — driven entirely by natural language.

/

Extensible with plugins

Add slash commands, specialized agents, hooks, and MCP servers. This repo ships 13 official plugins to start from.

▶

Runs and verifies

Executes tests, linters, and builds, then iterates on failures until things actually pass — not just until the code looks right.

⛭

Hooks & automation

Intercept tool calls, enforce policies, and wire up session automation with configurable hooks and settings.

Install

Up and running in one command

Install Claude Code, then run claude from your project directory.

macOS / Linux (recommended)
curl -fsSL https://claude.ai/install.sh | bash
Homebrew (macOS / Linux)
brew install --cask claude-code
Windows (recommended)
irm https://claude.ai/install.ps1 | iex
WinGet (Windows)
winget install Anthropic.ClaudeCode
