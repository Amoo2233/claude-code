Official plugins

Plugins extend Claude Code with custom slash commands, specialized agents, hooks, skills, and MCP servers. These 13 ship in the repository's plugins directory; install them (and community plugins) with the /plugin command.

agent-sdk-dev

Development kit for the Claude Agent SDK: interactive project setup plus agents that validate SDK apps against best practices.

/new-sdk-app2 agents

code-review

Automated PR review using five parallel specialized agents with confidence-based scoring to filter out false positives.

/code-review5 agents

commit-commands

Git workflow automation for committing, pushing, and creating pull requests with streamlined slash commands.

/commit/commit-push-pr/clean_gone

feature-dev

Structured 7-phase feature development workflow with dedicated agents for codebase exploration, architecture, and review.

/feature-dev3 agents

frontend-design

Auto-invoked guidance for building distinctive, production-grade frontends that avoid generic AI aesthetics.

skill

hookify

Create custom hooks that prevent unwanted behaviors, by analyzing conversation patterns or following explicit instructions.

/hookifyagentskill

pr-review-toolkit

Six review agents specializing in comments, tests, error handling, type design, code quality, and simplification.

/review-pr6 agents

plugin-dev

Toolkit for building plugins: an 8-phase guided creation workflow backed by seven expert skills and validator agents.

/create-plugin3 agents7 skills

security-guidance

PreToolUse hook that warns about nine security patterns — command injection, XSS, eval, pickle deserialization, and more.

hook

Self-referential AI loops for iterative development: Claude works the same task repeatedly until it's complete.
